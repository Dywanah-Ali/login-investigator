## Phishing awareness

The team discussed a follow-up to the phishing awareness email sent on 2026-08-19. The next message should repeat the practical advice rather than add a long list of examples. Isabel will prepare a draft that keeps the two main instructions prominent: do not enter a password after following an email link, and do not approve an MFA request you did not start.

The project remains in preparation. The proposed route is a self-service password reset portal on the intranet. The team needs to check the identity verification steps and the wording staff see if they cannot complete the process. No change to the current helpdesk reset process was agreed today.

Ruby will bring common support questions to the project discussion. Staff must continue contacting the helpdesk for resets until the launch is announced and the process is available.

Isabel owns the awareness draft for 2026-09-15. Ruby owns the support questions for the same date. Freya will prepare the travel reminder this week. Thomas asked that each action return with a clear outcome, including any reason it needs more time.
