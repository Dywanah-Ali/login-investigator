
**Turn**:
One question inside an Investigation together with everything that answered it: the agent's
answer, its tool calls, or an incident report.
_Avoid_: Message, exchange

**Report offer**:
The incident-report action the Investigation currently allows: write a first report, update it
after new answers, or nothing when a report would add nothing new.
_Avoid_: Report button

**Dataset**:
The sign-in log the application analyses, loaded once from a configured source, with its facts
(capture time, date bounds, countries, users) and the findings the rules produce on all of it.
_Avoid_: The CSV, the file
