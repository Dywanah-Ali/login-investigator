What you would read and learn

  • About 3,000 lines, and every line ends up in v2. Nothing arrives that has to be understood only to be deleted.

What you would read and learn

  • About 3,700 lines, of which the template's AI SDK transport and server route are deleted. The UI left over is the same official message components A uses.
  • Three new ideas to learn: the App Router's folder-as-route rule, server versus client components, and why a second server runs beside FastAPI without doing any work.
  • Risk: Next.js exists to run code on the server. v2 has no server-side frontend work, so every Next.js feature is a thing to switch off or avoid. For a reviewer, that is noise.
  • Nothing here is unavailable on Vite. shadcn/ui lists seven setups as equal and recommends none.
